# رفع ساحة العقبة على سيرفر سحابي — الخطوات كاملة

النظام يبقى كما هو: **خادم واحد يقدّم الصفحات والبيانات معاً** — لا فصل بين
واجهة وخادم، ولا تعديل في الشيفرة. كل ما يلزم: سيرفر، ورفع الملفات، وأمر
تجهيز واحد.

## 1) استئجار السيرفر

- المزوّد: Hetzner (باقة CX22 ~4 يورو شهرياً) أو DigitalOcean أو ما يشبههما.
- النظام: **Ubuntu 24.04**.
- عند الإنشاء يظهر **عنوان IP** — احتفظ به، وكلمة/مفتاح دخول root.

## 2) اسم النطاق (للرابط الآمن https)

- اشترِ نطاقاً (مثل aqaba-yard.com — ~10 دنانير سنوياً) من Namecheap أو غيره.
- في إعدادات النطاق أنشئ **سجل A** يشير إلى IP السيرفر.
- بلا نطاق يمكن التجربة على `http://IP:8787` لكن **لا تعمل عليه دائماً بلا
  https** — كلمات الدخول تمشي مكشوفة.

## 3) رفع ملفات التطبيق

من جهازك بواسطة **WinSCP** (اتصال SFTP إلى IP بمستخدم root):

- أنشئ المجلد `/opt/aqaba-yard` وارفع إليه من مجلد التطبيق:
  **`dist` و`src` و`package.json` و`deploy`**.
- **لا ترفع `node_modules`** — الخادم يثبّتها لنفسه (نسخ ويندوز لا تعمل
  على لينكس).

## 4) أمر التجهيز الواحد

من PowerShell على جهازك:

```
ssh root@IP
bash /opt/aqaba-yard/deploy/cloud/cloud-setup.sh yard.example.com
```

(استبدل النطاق بنطاقك.) الأمر يثبّت Node ويشغّل النظام خدمةً دائمة تنهض
مع السيرفر، ويركّب https تلقائياً، ويغلق كل المنافذ غير اللازمة.

## 5) أول فتح ونقل بيانات المكتب

1. افتح `https://نطاقك` — يطلب تهيئة **كلمة المالك**: اجعلها طويلة وقوية،
   فالنظام صار على الإنترنت العام.
2. من جهاز المكتب: زر **«نسخة احتياطية»** ينزّل ملف `.db`.
3. من السحابة: **أدوات التدريب ← الاسترجاع** وارفع الملف — يعود كل شيء:
   الحاويات والحركات والصور والتصاريح وحسابات السائقين والموظفون.

## 6) التحديثات لاحقاً

ارفع `dist` و`src` الجديدة إلى `/opt/aqaba-yard` (استبدالاً) ثم:

```
ssh root@IP systemctl restart aqaba-yard
```

## 7) عادة النسخ الاحتياطي

زر النسخة الاحتياطية من المتصفح ينزّل الملف **إلى جهازك أنت** — اجعلها
عادة أسبوعية على الأقل: بياناتك عندها في مكانين دائماً.

## تنبيهات

- أرقام PIN للموظفين: غير متوقعة (لا 1234).
- النظام يخنق محاولات الدخول الفاشلة تلقائياً، لكن قوة كلمة المالك تبقى
  خط الدفاع الأول على الإنترنت العام.
- جهاز المكتب يصير مجرد متصفح كأي جهاز — السيرفر السحابي هو الحقيقة
  الواحدة للبيانات.
